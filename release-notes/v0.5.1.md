Generated files and tests stay out of your way, so the review shows the code you need to read.

## Improved

- **Guided review skips generated files**: lockfiles, build output, snapshots and generated code are left out of the sections and the progress count, so you never open or tick them. The toolbar says how many were left out, and the Files view still shows them.
- **Your own generated files**: list more in **Settings › Review › More generated files**, one glob per line (for example `**/*.gen.ts` or `api/openapi/`). They're treated like the built-in ones, and the agent skips them too.
- **Tests hidden by default**: the guided review leaves test and spec files out, and the Files view folds them until you choose **Show diff**. The agent still reads them to check what's covered. Turn it off with **Settings › Review › Hide test files**.

## Fixed

- Tabs in diffs and code blocks took up 8 columns. They now take 2.

## Install

| Platform | File |
|---|---|
| macOS (Apple silicon) | `BetterLGTM_0.5.1_aarch64.dmg` (signed and notarized) |
| macOS (Intel) | `BetterLGTM_0.5.1_x64.dmg` (signed and notarized) |
| Windows | `BetterLGTM_0.5.1_x64-setup.exe` or `.msi` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

On macOS you can also run `brew install --cask drmas/tap/betterlgtm`.

You'll need the [GitHub CLI](https://cli.github.com/) and one of [Claude Code](https://claude.com/claude-code), [Codex](https://developers.openai.com/codex/cli) or [Gemini CLI](https://geminicli.com), installed and signed in. Windows builds aren't signed yet: if SmartScreen warns, choose **More info → Run anyway**.
