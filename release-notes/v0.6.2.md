Copilot CLI as a review agent, a handoff to your coding agent for your own pull requests, double-checked description claims, and zoom.

## New

- **Copilot CLI (experimental)**: run reviews with GitHub Copilot CLI. Choose it during setup or in **Settings › Agent**. Like the other agents, it runs read-only. Thanks to @ahmedmandur.
- **Copy for agent**: on your own pull requests, **Submit review** can copy the findings you checked as one prompt for your coding agent, with the file and line, the fix, and what you dismissed as intended. Right-click a finding to copy just that one. Thanks to @ahmedashraffcih.
- **Double-checked claims**: the second pass now checks the description claims as well as the findings. Claims it confirms are marked **Double-checked**, and ones it corrects show what changed.
- **Changes not in the description**: the description check lists the changes the description doesn't mention, each linked to its lines.
- **Zoom**: make the whole window bigger or smaller with ⌘= and ⌘- (Ctrl on Windows and Linux). ⌘0 resets it, and **Settings › General** has the same choice.

## Changed

- **Dismissals from other pull requests**: a finding you dismissed elsewhere in the repository now only hides the same point in the same file, not similar ones. The analysis lists the dismissals it used.

## Fixed

- **Windows**: a console window no longer flashes for every background command.
- **macOS**: the sidebar follows the app's theme instead of the system's. Thanks to @ahmedashraffcih.

If you have 0.2.1 or later, choose **Install update** in the status bar.

## Install

| Platform | File |
|---|---|
| macOS (Apple silicon) | `BetterLGTM_0.6.2_aarch64.dmg` (signed and notarized) |
| macOS (Intel) | `BetterLGTM_0.6.2_x64.dmg` (signed and notarized) |
| Windows | `BetterLGTM_0.6.2_x64-setup.exe` or `.msi` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

On macOS you can also run `brew install --cask drmas/tap/betterlgtm`.

You'll need the [GitHub CLI](https://cli.github.com/) and one of [Claude Code](https://claude.com/claude-code), [Codex](https://developers.openai.com/codex/cli), [Gemini CLI](https://geminicli.com) or [Copilot CLI](https://docs.github.com/en/copilot/concepts/agents/about-copilot-cli), installed and signed in. Windows builds aren't signed yet: if SmartScreen warns, choose **More info → Run anyway**.
