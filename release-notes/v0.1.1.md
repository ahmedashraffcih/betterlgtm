The macOS app is now signed and notarized, and the app is called BetterLGTM.

## Changes

- **Signed and notarized on macOS.** The app opens like any other Mac app; no more "damaged" or "can't be opened" warnings.
- **New name.** The app, installers and window title now say BetterLGTM.
- **Open source.** BetterLGTM is now MIT licensed, with a [website](https://drmas.github.io/betterlgtm/), contributing guide and security policy.

## Install

| Platform | File |
|---|---|
| macOS (Apple silicon) | `BetterLGTM_0.1.1_aarch64.dmg` |
| macOS (Intel) | `BetterLGTM_0.1.1_x64.dmg` |
| Windows | `BetterLGTM_0.1.1_x64-setup.exe` or `.msi` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

You'll need the [GitHub CLI](https://cli.github.com/) and [Claude Code](https://claude.com/claude-code) installed and signed in.

Windows builds aren't signed yet: if SmartScreen warns about an unknown publisher, choose **More info → Run anyway**.
