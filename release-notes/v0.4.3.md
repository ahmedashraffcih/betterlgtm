Fixes for closing the window on macOS, hidden lines in the diff, and a few review mix-ups.

## Fixed

- **Closing the window on macOS**: the red close button and ⌘W didn't close the main window in 0.4.2. They close it again, along with the Settings window if it's open.
- **Show hidden lines**: in files where earlier changes added or removed lines, the expanded lines showed the wrong code against the wrong line numbers. They're right now, and they reset when the diff changes (for example when you hide whitespace changes).
- **Edit description and Submit review**: moving to another pull request with the keyboard while one of these dialogs was open could save your text to that other pull request. The dialogs now block those keys and start fresh for each pull request.
- **Re-running the analysis**: findings you had added to your review could end up pointing at different findings. Your picks are now cleared when a new analysis arrives.
- **Open in editor**: this button and **Open worktree in VS Code** did nothing. They now open VS Code.
- **Blank window**: an analysis with an unknown severity or a missing title could blank the window each time you opened that pull request.

If you have 0.2.1 or later, choose **Install update** in the status bar.

## Install

| Platform | File |
|---|---|
| macOS (Apple silicon) | `BetterLGTM_0.4.3_aarch64.dmg` (signed and notarized) |
| macOS (Intel) | `BetterLGTM_0.4.3_x64.dmg` (signed and notarized) |
| Windows | `BetterLGTM_0.4.3_x64-setup.exe` or `.msi` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

You'll need the [GitHub CLI](https://cli.github.com/) and [Claude Code](https://claude.com/claude-code) installed and signed in. Windows builds aren't signed yet: if SmartScreen warns, choose **More info → Run anyway**.
