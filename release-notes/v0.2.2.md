Large pull requests now open.

## Changes

- **Fixed:** pull requests with more than 20,000 changed lines failed to load with "the diff exceeded the maximum number of lines". GitHub won't send diffs that large, so BetterLGTM now builds them from its local copy of the repository. The result is the same diff GitHub shows.

If you have 0.2.1, choose **Install update** in the status bar.

## Install

| Platform | File |
|---|---|
| macOS (Apple silicon) | `BetterLGTM_0.2.2_aarch64.dmg` (signed and notarized) |
| macOS (Intel) | `BetterLGTM_0.2.2_x64.dmg` (signed and notarized) |
| Windows | `BetterLGTM_0.2.2_x64-setup.exe` or `.msi` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

You'll need the [GitHub CLI](https://cli.github.com/) and [Claude Code](https://claude.com/claude-code) installed and signed in. Windows builds aren't signed yet: if SmartScreen warns, choose **More info → Run anyway**.
