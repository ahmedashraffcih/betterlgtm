The inbox loads again when you have a lot of review requests waiting.

## Fixed

- **Large review queues**: with a few hundred open review requests, usually from teams you're on, the inbox failed with `invalid character '<'`. GitHub was giving up on the search because it asked for too much at once. The inbox now loads pull requests 25 at a time, up to 200, so a big queue takes a little longer but always arrives. If GitHub still times out, the error says so.

If you have 0.2.1 or later, choose **Install update** in the status bar.

## Install

| Platform | File |
|---|---|
| macOS (Apple silicon) | `BetterLGTM_0.6.1_aarch64.dmg` (signed and notarized) |
| macOS (Intel) | `BetterLGTM_0.6.1_x64.dmg` (signed and notarized) |
| Windows | `BetterLGTM_0.6.1_x64-setup.exe` or `.msi` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

On macOS you can also run `brew install --cask drmas/tap/betterlgtm`.

You'll need the [GitHub CLI](https://cli.github.com/) and one of [Claude Code](https://claude.com/claude-code), [Codex](https://developers.openai.com/codex/cli) or [Gemini CLI](https://geminicli.com), installed and signed in. Windows builds aren't signed yet: if SmartScreen warns, choose **More info → Run anyway**.
