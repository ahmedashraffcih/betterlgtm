A faster BetterLGTM: quicker startup, instant PR switching and smoother big diffs.

## Faster

- **Startup**: the inbox shows its last copy right away and refreshes from GitHub in the background. Parts of the app you don't see at launch load after the first paint.
- **Switching PRs**: PRs you opened recently reopen instantly. A PR starts loading when you rest the pointer on it, and the PRs next to the one you're reading load ahead, so j/k is quick. The diff appears before the description and conversations finish loading.
- **Big diffs**: syntax highlighting runs in the background and is remembered per file. Typing and Claude's live output no longer redraw the diff, and long files render as you scroll. Switching to a 4,000-line file went from about 2.4 s to under 0.5 s in our tests.

## Fixed

- The main button in dialogs (like **Request changes**) lost its color on hover in dark mode.

If you have 0.2.1 or later, choose **Install update** in the status bar.

## Install

| Platform | File |
|---|---|
| macOS (Apple silicon) | `BetterLGTM_0.4.1_aarch64.dmg` (signed and notarized) |
| macOS (Intel) | `BetterLGTM_0.4.1_x64.dmg` (signed and notarized) |
| Windows | `BetterLGTM_0.4.1_x64-setup.exe` or `.msi` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

You'll need the [GitHub CLI](https://cli.github.com/) and [Claude Code](https://claude.com/claude-code) installed and signed in. Windows builds aren't signed yet: if SmartScreen warns, choose **More info → Run anyway**.
