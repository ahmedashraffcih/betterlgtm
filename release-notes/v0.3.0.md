Better reviews: findings you can act on, suggestions authors can apply, and the full context of a pull request in one place.

## New

- **Suggested changes.** When a fix is small and certain, Claude writes the exact replacement, and Submit review can post it as a GitHub suggestion the author applies in one click.
- **Finding states.** Resolve a finding, or dismiss it with a reason, and reopen it later. Posted findings are marked Commented. States survive re-runs, and Submit review leaves handled findings unchecked.
- **Drafted review summary.** **Draft with Claude** in Submit review writes the summary from your decision and comments. You edit it before posting.
- **Existing conversations.** Review threads already on the pull request appear under Conversations with their code and comments, and Claude is told about open ones so it doesn't repeat them.
- **Linked issues.** The analysis also checks the pull request against the issues it closes, and the header links them.
- **Risk and tests.** The overview shows the risk level and its reasons, test lines against code lines, the sensitive areas touched, and whether each significant change is tested.
- **Review guidelines.** Claude follows a repository's REVIEW.md or the review section of CONTRIBUTING.md, and Settings › Claude can hold instructions for a single repository.
- **Auto-analyze (optional).** Analyze new review requests in the background, one to three at a time, with a notification when each is ready. Off by default; turn it on in Settings › Claude.

If you have 0.2.1 or later, choose **Install update** in the status bar.

## Install

| Platform | File |
|---|---|
| macOS (Apple silicon) | `BetterLGTM_0.3.0_aarch64.dmg` (signed and notarized) |
| macOS (Intel) | `BetterLGTM_0.3.0_x64.dmg` (signed and notarized) |
| Windows | `BetterLGTM_0.3.0_x64-setup.exe` or `.msi` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

You'll need the [GitHub CLI](https://cli.github.com/) and [Claude Code](https://claude.com/claude-code) installed and signed in. Windows builds aren't signed yet: if SmartScreen warns, choose **More info → Run anyway**.
