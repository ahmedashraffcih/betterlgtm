The first release of betterlgtm: a desktop app for reviewing GitHub pull requests with Claude Code.

## Highlights

- **Review inbox.** Lists the pull requests waiting for your review through the `gh` CLI, grouped by organization, refreshed on a timer. Hide organizations you don't care about.
- **A worktree per PR.** Each pull request is checked out in its own git worktree, so Claude Code reads the real code, not just the diff.
- **Analysis you can skim.** Claude compares the description with the implementation and gives a verdict, a short summary, and the findings that need your attention, each linked to the lines it is about.
- **Guided review.** Changes are grouped into sections that explain what each part does, in one continuous scroll. Mark changes, files or whole sections as reviewed and see your progress.
- **Diff view.** A file-by-file diff with search, reviewed checkboxes, and generated files folded away until you open them.
- **Chat.** Ask Claude follow-up questions about the PR; it knows which finding, section or file you're looking at.
- **Desktop ergonomics.** Menu bar, command palette (Ctrl+K), keyboard shortcuts, light and dark themes, and layouts that work in narrow windows.
- **Settings.** Organizations to watch, refresh interval, extra review instructions, Claude model and effort, tool paths, and the data folder.

Claude Code runs read-only: it can read files, search and look at git history, but cannot change your code or post anything to GitHub.

## Requirements

- [GitHub CLI](https://cli.github.com/), signed in (`gh auth login`)
- [Claude Code](https://claude.com/claude-code), signed in
- Linux: WebKitGTK 4.1

## Install

| Platform | File |
|---|---|
| macOS (Apple silicon) | `betterlgtm_0.1.0_aarch64.dmg` |
| macOS (Intel) | `betterlgtm_0.1.0_x64.dmg` |
| Windows | `betterlgtm_0.1.0_x64-setup.exe` or `.msi` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

These builds are not code-signed yet.

- **macOS:** if the app "is damaged" or "can't be opened", run `xattr -dr com.apple.quarantine /Applications/betterlgtm.app` once.
- **Windows:** SmartScreen may warn about an unknown publisher; choose **More info → Run anyway**.

## Known limitations

- Submitting a review from the app isn't available yet; use GitHub for that.
- No auto-update; download new versions from Releases.
