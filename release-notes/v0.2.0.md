BetterLGTM now updates itself.

## Changes

- **Automatic updates.** The app checks for new versions in the background. When one is out, choose **Install update** in the status bar, then **Restart to finish updating**. Nothing downloads until you choose to. Turn the checks off in **Settings › General**, or run one any time from **Help › Check for updates**.
- Updates are signed, and the app only installs ones signed by the BetterLGTM release key.

This is the last version you need to download by hand. On Linux, automatic updates work for the AppImage; `.deb` and `.rpm` installs are updated by downloading the new package.

## Install

| Platform | File |
|---|---|
| macOS (Apple silicon) | `BetterLGTM_0.2.0_aarch64.dmg` (signed and notarized) |
| macOS (Intel) | `BetterLGTM_0.2.0_x64.dmg` (signed and notarized) |
| Windows | `BetterLGTM_0.2.0_x64-setup.exe` or `.msi` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

You'll need the [GitHub CLI](https://cli.github.com/) and [Claude Code](https://claude.com/claude-code) installed and signed in. Windows builds aren't signed yet: if SmartScreen warns, choose **More info → Run anyway**.
