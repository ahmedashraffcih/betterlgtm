## New

- **Since your last review** ([#2](https://github.com/drmas/betterlgtm/issues/2)). When commits land after you reviewed a pull request, a bar shows how many and when you reviewed. Switch the diff to just those changes, or choose **Analyze new changes** to have Claude look only at them. If the branch was force-pushed and your reviewed commit is gone, you get all changes instead.
- **Open any pull request.** Paste a GitHub PR link, or type `owner/repo#number`, in the command palette (**Ctrl+K**) to open a PR that isn't in your inbox, such as one you already reviewed.

## Fixed

- **"Config files … are not trusted" or other tool errors** when the app was started from inside a project folder with its own mise or direnv setup. The app now looks up your tools from your home folder.

If you have 0.2.1 or later, choose **Install update** in the status bar.

## Install

| Platform | File |
|---|---|
| macOS (Apple silicon) | `BetterLGTM_0.2.5_aarch64.dmg` (signed and notarized) |
| macOS (Intel) | `BetterLGTM_0.2.5_x64.dmg` (signed and notarized) |
| Windows | `BetterLGTM_0.2.5_x64-setup.exe` or `.msi` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

You'll need the [GitHub CLI](https://cli.github.com/) and [Claude Code](https://claude.com/claude-code) installed and signed in. Windows builds aren't signed yet: if SmartScreen warns, choose **More info → Run anyway**.
