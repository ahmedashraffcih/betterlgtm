A map of the pull request, with the unchanged files the change may reach.

## New

- **PR map**: **Diff › Map** draws the changed files grouped by folder, with the links between them. Each file shows its status, findings, sensitive areas and review state. Click a file to see what it does and what it touches, and double-click it to open its section or diff.
- **Files that may be affected**: the map can also show the unchanged files that import the changed ones, one or two imports away, with tests tagged. Choose **+ files that import them** or **+ two imports away** in the map's toolbar. Imports are read for TypeScript, JavaScript, Python, Go and Rust, including tsconfig paths and workspace packages. Double-click an affected file to open it in your editor.

## Fixed

- **Findings settled on GitHub**: a finding posted as a comment now shows as Resolved once its conversation is resolved on GitHub. The overview stops asking you to fix it, and re-runs and the chat don't report it again.
- **Linux**: a two-finger pinch on the map zooms the map, not the whole window.

If you have 0.2.1 or later, choose **Install update** in the status bar.

## Install

| Platform | File |
|---|---|
| macOS (Apple silicon) | `BetterLGTM_0.7.0_aarch64.dmg` (signed and notarized) |
| macOS (Intel) | `BetterLGTM_0.7.0_x64.dmg` (signed and notarized) |
| Windows | `BetterLGTM_0.7.0_x64-setup.exe` or `.msi` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

On macOS you can also run `brew install --cask drmas/tap/betterlgtm`.

You'll need the [GitHub CLI](https://cli.github.com/) and one of [Claude Code](https://claude.com/claude-code), [Codex](https://developers.openai.com/codex/cli), [Gemini CLI](https://geminicli.com) or [Copilot CLI](https://docs.github.com/en/copilot/concepts/agents/about-copilot-cli), installed and signed in. Windows builds aren't signed yet: if SmartScreen warns, choose **More info → Run anyway**.
