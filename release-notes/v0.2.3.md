Submit your review from BetterLGTM, see your own pull requests, and see where each review stands.

## New

- **Submit review.** Post your review to GitHub without leaving the app. The findings you pick become comments on their exact lines; edit each one, add a summary, and choose **Comment**, **Approve** or **Request changes**. One checkbox selects every finding. Findings outside the diff go into the review summary. Nothing is posted until you press the button.
- **Mine.** Switch the inbox between **To review** and **Mine** to see your own open pull requests.
- **Review status.** The pull request header shows GitHub's review decision, whether your review is requested, each reviewer's latest review, and who it's still waiting on.

## Improved

- Update checks retry when GitHub's downloads fail, and check a copy of the update feed on the website first.

If you have 0.2.1 or later, choose **Install update** in the status bar.

## Install

| Platform | File |
|---|---|
| macOS (Apple silicon) | `BetterLGTM_0.2.3_aarch64.dmg` (signed and notarized) |
| macOS (Intel) | `BetterLGTM_0.2.3_x64.dmg` (signed and notarized) |
| Windows | `BetterLGTM_0.2.3_x64-setup.exe` or `.msi` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

You'll need the [GitHub CLI](https://cli.github.com/) and [Claude Code](https://claude.com/claude-code) installed and signed in. Windows builds aren't signed yet: if SmartScreen warns, choose **More info → Run anyway**.
