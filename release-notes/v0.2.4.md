Finds `gh` and `claude` when opened from the Dock or a launcher.

## Fixed

- **"Could not run `gh`" on a fresh install** ([#1](https://github.com/drmas/betterlgtm/issues/1)). Apps opened from the Dock, Finder, Spotlight or a desktop launcher don't read your shell setup, so they couldn't find tools installed with Homebrew, npm or Claude Code's installer. BetterLGTM now uses your login shell's PATH and checks the usual install folders.

If you have 0.2.1 or later, choose **Install update** in the status bar.

## Install

| Platform | File |
|---|---|
| macOS (Apple silicon) | `BetterLGTM_0.2.4_aarch64.dmg` (signed and notarized) |
| macOS (Intel) | `BetterLGTM_0.2.4_x64.dmg` (signed and notarized) |
| Windows | `BetterLGTM_0.2.4_x64-setup.exe` or `.msi` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

You'll need the [GitHub CLI](https://cli.github.com/) and [Claude Code](https://claude.com/claude-code) installed and signed in. Windows builds aren't signed yet: if SmartScreen warns, choose **More info → Run anyway**.
