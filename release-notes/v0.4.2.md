BetterLGTM now looks and behaves like a native app on macOS, Windows and Linux, with a new LGTM logo.

## Native on every platform

- **Window**: the system draws the title bar and window buttons, so they match the rest of your desktop. On macOS the toolbar is the title bar, with the traffic lights beside it and a translucent sidebar. Windows 11 shows Mica behind the inbox.
- **Menu bar**: File, View, Review and Help are now real menus in the system menu bar. On macOS you also get the BetterLGTM, Edit and Window menus, including Hide, Close Window and Minimize.
- **Right-click menus**: right-click a pull request, a file or a finding to open it on GitHub, copy its link or path, mark it reviewed, add it to your review, or ask Claude.
- **Settings window**: on macOS, Settings (⌘,) opens in its own window.
- **Remembers your window**: the window reopens at the size and position you left it.
- **Looks at home**: control sizes and corner shapes follow each platform, and the inbox tabs fill the sidebar.

## Shortcuts

- Shortcuts use ⌘ on macOS and Ctrl on Windows and Linux. The Windows (Super) key no longer triggers them, and every shortcut label shows your platform's keys.
- **Refresh** is now ⌘R / Ctrl+R. F5 still works.
- **Find in diff**: ⌘F / Ctrl+F opens the diff search.
- The menu now shows the right keys for next and previous finding: **n** and **Shift+N**.

## Fixed

- The app logo reads **LGTM**.

If you have 0.2.1 or later, choose **Install update** in the status bar.

## Install

| Platform | File |
|---|---|
| macOS (Apple silicon) | `BetterLGTM_0.4.2_aarch64.dmg` (signed and notarized) |
| macOS (Intel) | `BetterLGTM_0.4.2_x64.dmg` (signed and notarized) |
| Windows | `BetterLGTM_0.4.2_x64-setup.exe` or `.msi` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

You'll need the [GitHub CLI](https://cli.github.com/) and [Claude Code](https://claude.com/claude-code) installed and signed in. Windows builds aren't signed yet: if SmartScreen warns, choose **More info → Run anyway**.
