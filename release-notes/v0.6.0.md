Shortcuts you can see while you hold ⌘ or Ctrl, a summary of what changed after each update, and anonymous usage stats you can turn off.

## New

- **Shortcut hints**: hold ⌘ on macOS, or Ctrl on Windows and Linux, and every button that has a shortcut shows its keys. Shortcuts without a button are listed at the bottom of the window. Press a key while still holding to run it.
- **New shortcuts**: ⌘E / Ctrl+E opens the worktree in your editor, and ⌘⇧O / Ctrl+Shift+O opens the pull request on GitHub.
- **What's new**: the first time an updated version opens, a short summary of the release shows. It doesn't show on a fresh install. Read it again from **Help › What's new**.
- **Anonymous usage stats**: the app counts how often it's opened, how many analyses and reviews are done, and which features are used, with the app version and your operating system. It never sends code, findings, chat, or repository, pull request or account names. Turn it off in **Settings › General › Share anonymous usage stats**.

If you have 0.2.1 or later, choose **Install update** in the status bar.

## Install

| Platform | File |
|---|---|
| macOS (Apple silicon) | `BetterLGTM_0.6.0_aarch64.dmg` (signed and notarized) |
| macOS (Intel) | `BetterLGTM_0.6.0_x64.dmg` (signed and notarized) |
| Windows | `BetterLGTM_0.6.0_x64-setup.exe` or `.msi` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

On macOS you can also run `brew install --cask drmas/tap/betterlgtm`.

You'll need the [GitHub CLI](https://cli.github.com/) and one of [Claude Code](https://claude.com/claude-code), [Codex](https://developers.openai.com/codex/cli) or [Gemini CLI](https://geminicli.com), installed and signed in. Windows builds aren't signed yet: if SmartScreen warns, choose **More info → Run anyway**.
