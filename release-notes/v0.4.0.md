Your own pull requests, and a much stronger diff.

## Your own PRs

- **What's blocking merge.** Draft status, conflicts or a branch behind its base, failing or running checks, requested changes, missing approvals and unresolved conversations, in one card.
- **Self-review.** Run the analysis on your own pull request before asking for reviews. Claude talks to you as the author and tells you whether it's ready.
- **Write the description.** **Edit with Claude** drafts the description from the diff, following your repository's PR template. Edit and preview it, then save it to GitHub.
- **Reply to feedback.** Reply to review conversations from the app, with **Draft reply with Claude** reading the code first, and resolve or reopen them.

## The diff

- **Syntax highlighting** for common languages, with word-level marks for what changed within a line.
- **Show hidden lines** between and after hunks, and hide whitespace-only changes.
- **Files with findings.** Finding counts in the file list and a filter for them.
- **Comment on lines.** Click a line number (shift-click to extend), then **Ask Claude** or **Add comment**. Line comments go into Submit review.
- **Search.** Regex and case-sensitive search across the diff, in all, added or removed lines or file paths, plus a search of the whole repository to find callers of changed code.

If you have 0.2.1 or later, choose **Install update** in the status bar.

## Install

| Platform | File |
|---|---|
| macOS (Apple silicon) | `BetterLGTM_0.4.0_aarch64.dmg` (signed and notarized) |
| macOS (Intel) | `BetterLGTM_0.4.0_x64.dmg` (signed and notarized) |
| Windows | `BetterLGTM_0.4.0_x64-setup.exe` or `.msi` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

You'll need the [GitHub CLI](https://cli.github.com/) and [Claude Code](https://claude.com/claude-code) installed and signed in. Repository search also needs [ripgrep](https://github.com/BurntSushi/ripgrep). Windows builds aren't signed yet: if SmartScreen warns, choose **More info → Run anyway**.
