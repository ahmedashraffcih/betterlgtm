Keep up with your reviews: a prioritized inbox, notifications, re-checked findings, and vim-style keys.

## New

- **Prioritized inbox** ([#4](https://github.com/drmas/betterlgtm/issues/4)). Each pull request shows its CI status, review decision, lines changed and a risk estimate (hover it for the reasons: size, failing CI, or auth, migration, CI and dependency files). The filter button opens **Sort and filter**: sort by risk, waiting time, size or last update; filter by CI, risk, review decision, analysis and drafts; and choose which organizations and repositories to show. Your choices are kept.
- **Notifications** ([#5](https://github.com/drmas/betterlgtm/issues/5)). A desktop notification when a review is requested from you, or requested again, and a count of waiting reviews on the app icon (macOS and supported Linux desktops). Turn it off in **Settings › General**.
- **Re-check findings** ([#3](https://github.com/drmas/betterlgtm/issues/3)). When a pull request has new commits since the analysis, choose **Re-check findings**: Claude marks each finding fixed, still open, partly fixed or unclear, with a short note. Fixed findings start unchecked in Submit review.
- **Vim-style keys.** `h`/`l` move between the inbox, the list and the content; `j`/`k` move inside a pane; `gg`/`G`, `Ctrl+D`/`Ctrl+U`; `n`/`N` step through findings and `]`/`[` through files or sections; `x` marks reviewed, `a` adds a finding to the review, `S` submits. Press `?` for the full list, or turn them off in **Settings › General**.

## Changed

- `j`/`k` now move within the focused pane; use `n`/`N` for the next and previous finding.

If you have 0.2.1 or later, choose **Install update** in the status bar.

## Install

| Platform | File |
|---|---|
| macOS (Apple silicon) | `BetterLGTM_0.2.6_aarch64.dmg` (signed and notarized) |
| macOS (Intel) | `BetterLGTM_0.2.6_x64.dmg` (signed and notarized) |
| Windows | `BetterLGTM_0.2.6_x64-setup.exe` or `.msi` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

You'll need the [GitHub CLI](https://cli.github.com/) and [Claude Code](https://claude.com/claude-code) installed and signed in. Windows builds aren't signed yet: if SmartScreen warns, choose **More info → Run anyway**.
