Choose the coding agent that reviews your pull requests, a first-run setup, and findings that are checked twice.

## New

- **Claude Code, Codex or Gemini CLI**: pick the agent that reads the code during setup or in **Settings › Agent**. Each runs read-only: Claude Code with a fixed list of read-only tools, Codex in its read-only sandbox, Gemini CLI in plan mode. Buttons and messages name the agent you chose.
  - Codex may search the web during a review, and doesn't report cost.
  - Gemini CLI support is experimental.
  - The spending limit for automatic analyses works with Claude Code only.
- **Onboarding**: the first run checks the GitHub CLI, your coding agent and Git, shows the command that fixes anything missing or signed out, and checks again when you come back to the window. Then pick your agent and what the inbox shows. **Try a sample pull request** shows a finished review on built-in data, without GitHub or an agent. Run either again from **Help › Check setup…** and **Help › Try a sample pull request**.
- **Double-checked findings**: after the analysis, a fresh session checks each finding against the code. Confirmed ones are marked **Double-checked**; ones it disproves move to a collapsed list, so you can still see them. Turn it off in **Settings › Agent**.
- **Spending limit**: automatic analyses stop at a limit you choose, $5 by default.

## Improved

- The analysis knows what your last review found and what you dismissed in the same repository, so it doesn't repeat itself.
- The guided review is written in the background after the analysis, so findings show sooner.
- Review sessions are saved in the app data folder instead of the window's storage, which could fill up on large reviews. Existing sessions move over on first launch, and are saved when you close the window.
- An empty inbox explains why it's empty and what to try.
- Chat, drafting buttons and progress messages say "Ask Codex", "Draft with Gemini" and so on, following the agent you chose.

If you have 0.2.1 or later, choose **Install update** in the status bar.

## Install

| Platform | File |
|---|---|
| macOS (Apple silicon) | `BetterLGTM_0.5.0_aarch64.dmg` (signed and notarized) |
| macOS (Intel) | `BetterLGTM_0.5.0_x64.dmg` (signed and notarized) |
| Windows | `BetterLGTM_0.5.0_x64-setup.exe` or `.msi` |
| Linux | `.AppImage`, `.deb` or `.rpm` |

On macOS you can also run `brew install --cask drmas/tap/betterlgtm`.

You'll need the [GitHub CLI](https://cli.github.com/) and one of [Claude Code](https://claude.com/claude-code), [Codex](https://developers.openai.com/codex/cli) or [Gemini CLI](https://geminicli.com), installed and signed in. Windows builds aren't signed yet: if SmartScreen warns, choose **More info → Run anyway**.
