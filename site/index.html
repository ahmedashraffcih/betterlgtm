A desktop app for the pull requests waiting on your review. It checks each one out, has Claude Code compare the description with the code, and walks you through the changes in an order that makes sense.

Download for free Free for macOS, Windows and Linux. Other platforms

Does the code do what the description says?

Claude Code reads the pull request in its own checkout, then checks each claim from the description against what the code actually does. When a claim doesn't hold, you get the reason and the exact lines.

Read the change, not the file list

Related edits are grouped into sections with a line on what each one does, in one continuous scroll. Tick off a section, a file or a single change as you go, and generated files stay folded until you open them.

Ask about the line you're on

The chat knows which finding, section or file you're looking at, and Claude can read the whole repository to answer. It can't change your code or post anything to GitHub.

How would you fix the double charge?
Take a short lock on the key before charging: SET idem:lock:{key} NX EX 30 in store.ts:19. A second request that can't get the lock waits for the first response instead of charging again.

Runs on your machine, with the tools you already use

No account, no server

BetterLGTM talks to GitHub through your signed-in gh and to Claude through your claude. Your code and tokens never pass through us.

A worktree per pull request

Each PR gets its own checkout next to a shared clone, so Claude reads real files and your working copy is never touched.

Read-only by design

Claude Code can read, search and look at git history. It can't edit files, run other commands, or comment on GitHub.

Open source

MIT licensed. Read the code, file an issue, or send a pull request on GitHub.
